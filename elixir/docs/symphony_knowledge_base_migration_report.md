## Какие противоречия устранены

- Общий механизм Symphony отделён от проектного профиля agent-runner.
- Прежнее описание «runner ещё нужно создать» заменено фактическим состоянием с сохранением незакрытой приёмки.
- Источник исполняемого workflow уточнён: template профиля → локально сгенерированный WORKFLOW установки. Правило отсутствия WORKFLOW в app сохранено.
- Стартовая concurrency `1–2` заменена описанием текущего ограниченного пилота: одна выбранная карточка и один незавершённый цикл.
- Создание PR описано через controller после остановки worker и проверки bundle.
- Уточнено наличие `pr-ci.yml` и `verify.yml` в app; наличие workflow отделено от проверки required checks на GitHub.
- Dev validation и внутренний completed отделены от production/Done. Незавершённый post-merge status sync явно указан.
- Реализованный state store больше не описывается как ещё не сделанный выбор; эксплуатационные условия остаются открытыми.
