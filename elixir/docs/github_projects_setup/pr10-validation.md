548 Elixir tests, 0 failures, 6 skipped, 100% измеряемого покрытия; 17 Python tests,
format/specs/Credo и Dialyzer без ошибок. Сохранены лог и итоговый exit code `0` в
игнорируемом `elixir/log/pr10-queue-all.log` / `pr10-queue-exit.txt`.
Целевой прогон новых форм/цикла: 26 тестов, 0 ошибок. Ниже сохранены результаты
основной реализации до этого дополнения.

Новые сценарии: настоящая проверка fixture ZIP через observer и принятие отдельного
свидетельства; отсутствие artifact, защитная пауза, сломанные finalizers, неполные
данные; новая попытка/SHA/artifact/policy; истечение 30 минут и перевод часов назад;
идемпотентность, рестарт store, restore, проблема среды, сохранение операторской паузы;
завершение merged-цикла, отмены и возврат исходного owner после recovery.
Повторное подтверждение Queue сбрасывает baseline, чтобы не повторно использовать
прежнюю validation. Изменение/expiry записывает отдельное аннулирование через Gate.

итоги выше зафиксированы из уже полученного вывода. Финальный exit code оболочки

актуальной версии перед сменой fixtures; ожидание fsync учитывает нагрузку WSL.
Проверены взаимные блокировки паузы с recovery и с ещё не отправленной публикацией.

Дополнительно в браузере пройдено обновлённое демо с inherited pause: заполнены
