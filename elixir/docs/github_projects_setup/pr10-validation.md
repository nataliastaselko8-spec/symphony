- `mix pr_body.check` — `PR body format OK`; `git diff --check` — без ошибок.

При поступлении нового сообщения временный WSL process/log стал недоступен;
итоги выше зафиксированы из уже полученного вывода. Финальный exit code оболочки
этого полного запуска отдельно не сохранён. Это ограничение журналирования,
а не утверждение о дополнительном непройденном тесте.

Ранний прогон выявил смешанный `MIX_BUILD_PATH` для dev/test: из-за этого четыре
LiveView-теста не загружали протокол Enumerable для LazyHTML. В среде проверки
используется `MIX_BUILD_ROOT`, сохраняющий отдельные каталоги окружений. Версии
зависимостей ради этого не менялись. Порог покрытия и исключения не изменялись.
Тест переходов CI/review/deployment теперь дожидается завершённого наблюдения
актуальной версии перед сменой fixtures; ожидание fsync учитывает нагрузку WSL.
Проверены взаимные блокировки паузы с recovery и с ещё не отправленной публикацией.
